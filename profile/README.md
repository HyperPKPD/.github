# Hyper PKPD: Open Source Data Science

Hyper PKPD aims to build next-generation, high-performance software tools designed for data science, clinical pharmacology, and pharmacometrics. The mission is to simplify complex quantitative modeling workflows by crafting scalable, modern interfaces and developer-friendly frameworks.

---

### Projects

- **Scalable User Interfaces:** Designing intuitive workflows and GUIs/APIs for data science.
- **Integration:** Bridging advanced statistical computing, quantitative clinical pharmacology, and modern software engineering.
- **High-Performance Tools:** Building faster, efficient engine components and helper packages for quantitative analysis.
